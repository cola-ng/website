# Amigo 接入主网站

唯一网站与后端位于 `website`。机器人业务为 `crates/server/src/services/amigo`，路由 `/api/amigo`，与账号、学习等网站模块在同一 Rust 进程中运行。智能学伴已迁为原生 Rust/Glory/Sapid 页面：登录后访问 `/amigo`，逐台配置页为 `/amigo/devices/{id}`。

相邻的 `amigo` 仓库仅维护固件、板级驱动、共享协议及硬件工具。server 使用网站仓库中 `vendor/amigo` 的可校验源码快照，正常构建只需检出 website。更新共享协议时相邻检出 amigo，运行 `python scripts/sync-amigo-protocol.py` 并将快照差异与调用方一起审查提交。原 `amigo/crates/server`、`core`、`desktop` 和 `front` 已从活动目录移除。

## 本机运行

配置 website 的 `.env` 后运行：

```powershell
./scripts/Start-Colang.ps1 -Lan
# 已完成构建
./scripts/Start-Colang.ps1 -SkipBuild -Restart -Lan
```

`website/target/debug/colang.exe` 在 8119 同时提供网站、账号、设备配置和 WebSocket。网页来自 `front/dist`；日志在实际 Cargo target 下的 `amigo-server`。构建遵循正常 workspace 配置，不重定向 Cargo home、target 或 TEMP/TMP。

开发板继续连接 `ws://局域网IP:8119/api/amigo/session`，正式部署使用 WSS。UUID、设备密钥、Wi-Fi、Hi ESP 模型及英文屏幕界面均保持兼容，不需重新烧录。

两套旧服务曾共用 JWT 签名密钥，迁入账号又分配了新用户编号，因此本机网站的签名密钥已轮换，旧网页需重新登录一次。账号密码保留；设备密钥与 JWT 无关。

## AI 与配置

硬件后端使用主网站 `get_user_provider` 检查权限，沿用个人 AI 配置及付费平台服务规则，不允许通过 `AMIGO_AI_PROVIDER` 绕过权限。聊天、ASR、TTS 可以分别选择个人配置；MiniMax 机器人流式适配使用账号实际选择的密钥与区域。视觉请求也检查账号权限，个人配置失败不自动改用平台密钥。

本机迁入的机器人账号已配置其原有 MiniMax 聊天和智谱 ASR/TTS，可在“我的学习 → AI 服务设置”管理。密钥保存在服务器数据库中，网页列表会脱敏。

每台设备独立保存角色、称呼、音色、音量、连续对话、打断、摄像头、环境语音、学习及免打扰参数。硬件设置约五秒内下发，设备写入 NVS 后确认配置版本。离线设备重连后同步。添加设备使用屏幕六位验证码；移除设备会撤销连接权限。

## 验证码绑定

1. 新设备连接 Amigo-Setup 热点，在配网页面填写 Wi-Fi。固件内置服务地址；自建服务可展开“服务器设置”修改，不需填写设备密钥。
2. 联网后设备屏幕显示六位数字。登录网站“智能学伴 → 添加设备”，输入验证码与设备名称，即绑定到当前账号。
3. 设备自动检测绑定并连接语音服务。绑定不要求先配置 AI；账号尚无可用的聊天、ASR 或 TTS 时，设备保持在线并显示 “Online - configure AI”，设置仍正常下发；在账号设置完成配置后无需重新连接即可启用语音。

验证码有效期 5 分钟，过期自动换码。设备本地生成 256-bit 随机连接凭据并写入 NVS，服务器只保存哈希，正常网页不会接触长密钥。领取操作以行锁保证单一归属，同账号可重试；其他账号不可重复领取。验证码申请、轮询、账号和 IP 领取均有限流，响应禁止缓存。

已有设备保留原绑定、Wi-Fi、音量和协议。换账号需在实板 **Info → Pair → Confirm**，仅清除旧连接凭据并重启，保留 Wi-Fi 和音量，随后生成新码。旧账号的设备记录和历史不会转给新账号。恢复出厂 Wi-Fi 配网仍使用原 BOOT 长按功能。旧长密钥 API 仅为硬件工具与兼容性保留，不再作为网站的添加流程。

本机联调固件构建使用：

```powershell
../amigo/scripts/Build-AmigoBoard.ps1 -Board lichuang -Check -GatewayUrl ws://电脑局域网IP:8119/api/amigo/session
```

未传入构建地址时，默认正式 WSS 地址；开发板无法通过 127.0.0.1 访问电脑。已有 NVS 服务地址优先，不因更新固件改变。
