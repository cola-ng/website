## 已修复

| 范围 | 问题及修复 |
| --- | --- |
| 账户安全 | 已绑定的 Google / GitHub 仍显示绑定入口；现在只展示未绑定提供方，操作后重新读取账户状态。第三方账户未设置密码时不再显示无效的当前密码输入框。 |
| 解除绑定 | 服务端事务校验必须保留一种有效登录方式，并发解除也不能删除最后一种凭据；界面禁用相应按钮并说明如何继续。测试实际检查数据库删除与后续密码登录。 |
| OAuth | 服务端授权码 + PKCE、浏览器绑定、一次性结果；第三方令牌和密钥不进入前端。旧客户端自行声明 subject 的绑定接口关闭，历史未验证关联不能直接用于登录。修复回调重定向丢失 URL fragment。 |
| 权限 | 发送消息先校验对话归属；音频下载按当前用户过滤。已停用或锁定的账户不能继续使用旧 JWT，也不能绕过管理员权限校验。 |
| 对话速度 | 启用真实 SSE 流式回复；先显示英文，随后显示翻译和纠错。TTS 后台执行，复用提供方客户端连接，缩短提示词并只读取最近且有长度限制的上下文。 |
| 纠错质量 | 实测发现会把英式动词 `practise` 改为美式 `practice`；收紧为同时接受英美用法，只报告明确语法或用词错误，避免把有效表达和风格偏好当作错误。模型输出仍需持续质量评测。 |
| 对话恢复 | 防止同一对话并发生成；处理超时、断流、部分回复、页面离开和旧生成状态。重新打开生成中的对话会同步完成状态，避免一直显示处理中。修复历史翻页替换近期消息和查询方向错误。 |
| 提供方配置 | 对话现在使用用户启用的 AI 配置；生产旧豆包模型已关闭，改用真实验证通过的模型。应用层去掉包含 AI 密钥和语音转写正文的调试日志。 |
| 语音合成 | 去掉覆盖配置的硬编码音色，使用与资源匹配的实际配置；后台失败记录不含正文的诊断信息。 |
| 订阅页 | 公开套餐列表错误地要求登录，导致未登录浏览时返回 401；套餐列表公开，钱包、订阅状态和修改操作继续鉴权。 |
| 首次加载 | Nginx 压缩 WASM / JS / CSS；生产 Caddy 开启 gzip / zstd，HTML 要求重新验证缓存。WASM 下载期间显示加载提示。 |
| 部署 | 前端上游通过 `API_UPSTREAM` 配置，兼容生产 `colang_api:6019`；旧前端域名统一跳转到正式域名，避免 OAuth Cookie 来源不一致。 |

## 验证范围

`tests/run.ps1` 在独立本地 PostgreSQL 中运行 API、OAuth、数据库事务及实际 WASM 浏览器测试，不使用生产数据，也不调用外部 AI。包含 70 项 API 检查、29 项 OAuth HTTP 检查、15 个浏览器流程、38 个页面的两种宽度共 76 次页面检查，以及 18 项交互状态和流式响应回归。具体结果及截图保存在 workspace 的正常 `target_directory` 下。

生产复检另行验证公开页面、OAuth 跳转和取消、HTTPS Cookie、PKCE、压缩后的响应字节和解压校验，以及真实模型经由正式代理的逐段输出。真实第三方登录依赖提供方授权，不能用模拟数据代替；也不通过自动删除实际用户的唯一登录凭据来测试解除绑定。

2026-11-09 的生产抽样结果（不是延迟保证）：

| 检查 | 实测 |
| --- | --- |
| HTTPS WASM | 原始 3,630,234 字节，gzip 1,254,683 字节（减少 65.4%），zstd 1,149,692 字节（减少 68.3%）；gzip 解压后与原件一致 |
| 正式域名文字流 | 首段 2.691 秒，完整文字 3.525 秒，56 次增量更新，数据库保存成功；有效英式拼写未被误报 |
| 独立浏览器真实对话 | 首段显示 1.597 秒，整段完成 2.415 秒，包含浏览器网络链路 |
| 语音输出 | 文字先完成，约 7.969 秒音频生成并可下载，MIME 为 audio/mpeg |
| 语音输入 | 实际识别单声道 16 kHz WAV，首段回复 6.289 秒，文字完成 7.971 秒，用户音频保存成功 |

浏览器与服务器测得的延迟不同，受网络、提示词及模型负载影响。测试使用独立的临时账户和合成语音，不读取真实用户的浏览器凭据。

## 后续仍可改进

- 重置、删除对话后的音频文件可增加定期清理，避免磁盘长期增长；应与正在生成的语音任务协调后再删除。
- 按账户限制 AI 并发、频率和预算，需结合套餐及实际用量制定策略；本次只限制同一对话并发，未改变计费规则。
- 当前 WASM 压缩后仍约 1.2 MB，跨地区首次下载依赖网络质量；可以继续评估 WASM 体积优化、CDN 和缓存策略。
- 仓库已有未使用代码等编译警告，需要独立清理；本次保持前端 Clippy 零警告，并运行后端编译和针对行为的回归。
- 当前锁定版本的语音 SDK 内部仍有打印请求正文的调试输出；应用层已移除自己的敏感调试日志，后续升级或修订 SDK 时应一并关闭底层输出。
