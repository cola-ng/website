# Glory / Sapid 界面对照

对照基准为迁移前最后一个 React 提交 `b486031a`。参考源文件和依赖仅放在 Cargo metadata 返回的 `target_directory/ui-reference` 中，不属于发布内容；线上继续使用 Glory / Sapid WASM。

本次恢复的结构和交互：

- 紧凑的五项学习导航、移动端菜单和账户下拉入口。
- 首页的欢迎与查词区、学习统计、学习时长柱图、角色扮演、任务和洞察侧栏。
- 个人页的封面、账户信息、编辑资料及“个人资料 / 成就 / 设置”标签。密码和 AI 配置按需打开弹窗。
- 词典 / 翻译切换、词条分区和查询历史侧栏，游客历史沿用旧版 `dict_search_history`；支持 Enter 查询、清理历史和复制译文。
- 聊天列表与消息分别滚动、场景与改名弹窗、底部输入区、中英文显示偏好、Enter 发送及 Shift + Enter 换行。向上加载历史时保留阅读位置，流式回复跟随底部。
- 智能复习和五种练习入口；智能复习按每条推荐内容的实际类型展示练习。
- 跟读主题选择弹窗、进度和结构化发音评分。
- 后台统计卡片、用户与财务表格、内容列表和新建 / 编辑弹窗，以及分类和跟读管理标签。

发布时继续保留旧的哈希资源以兼容已打开的页面；wasm-bindgen 的固定路径辅助脚本设置为重新校验缓存，新版使用 `platform.js`，防止浏览器把旧导出与新 WASM 混用。

继续保留迁移后的橙色交互主题、统一字号、Handle、头像管理、已验证的 Google / GitHub 绑定状态、真实解绑限制、自备 AI 服务和付费权限规则。旧版固定的“85% 正确率”以及无实际数据的周 / 月占位柱图不再使用；统计读取真实接口，空值明确显示为缺少记录。

## 复检

`tests/run.ps1` 在隔离 PostgreSQL、API 与模拟外部服务中运行 API、权限、OAuth、流式对话及浏览器回归。`ui.cjs` 对 39 个入口进行桌面和手机检查，验证配色、字号、溢出、焦点、错误和处理中状态。

`tests/parity.cjs` 对参考 React 页面与实际 WASM 页面注入相同数据，保存桌面 / 手机截图，并检查页面分区、标签切换、键盘操作、弹窗、聊天视口、混合复习和游客查词历史。它默认使用独立的本地预览地址 `127.0.0.1:5180` 和 `127.0.0.1:5178`；用 `PARITY_VERSION=glory` 可仅复检新版。

输出在 `target_directory/qa-parity`，参考界面不要求像素完全相同：新增业务字段、安全修复、统一字号和真实数据会造成合理差异。不得为了截图一致恢复虚假统计、未验证绑定或免费账户的平台密钥回退。
