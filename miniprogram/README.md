# 开朗英语微信小程序

原生微信小程序（JavaScript / WXML / WXSS），直接复用 `website/crates/server` 的 `/api/` 接口。运行代码不依赖 npm 包，不需要打包网站 WASM，也不使用 web-view。微信开发者工具可直接导入本目录。

## 开始开发

1. 按 `../front/README.md` 启动现有 API，默认端口 `8119`，需要已初始化的 PostgreSQL 和项目正常的服务端配置。
2. 微信开发者工具导入 `website/miniprogram`，将 `project.config.json` 的 `touristappid` 替换为自己的小程序 AppID。游客模式仅用于代码查看与有限调试。
3. 修改 `config.js`。`develop` 默认 `http://127.0.0.1:8119`；使用本机接口时，仅在开发者工具的本地设置中关闭域名校验。`trial` / `release` 必须填写真实 HTTPS API 域名，留空会显示配置错误，不会回退到开发地址。
4. 手机预览需要手机能访问的 HTTPS 服务地址；手机上的 `127.0.0.1` 不指向开发电脑。录音、授权和音频播放应使用真实 AppID 在真机验证。
5. 体验和发布前，在微信公众平台配置同一 API 域名的 **request 合法域名**和 **downloadFile 合法域名**。音频通过带 Bearer header 的 `wx.downloadFile` 下载后播放，token 不出现在音频 URL 中。录音以 JSON Base64 通过 request 上传，不使用 uploadFile。

`project.private.config.json` 已忽略，可保存本机开发者工具设置。API Key 只在 AI 配置表单中短暂保留，提交给本站后端使用；不放入配置文件、本地 storage 或测试夹具。

## 平台适配

- 保留网站橙色主题，使用四个原生 tab：首页、词典、学习、我的。14 个页面均为原生模板。
- `/api/login`、`/api/register` 返回的 access token 保存在本机；401 清理当前登录态，402 显示服务端 AI 权限说明。切换账户清空页面私有状态；迟到的旧账户请求不能更新新账户页面。
- 对话使用 `wx.request({ enableChunked: true })` 接入网站 SSE，按字节拆帧后解码完整 UTF-8 行，处理中文、emoji、CRLF 与 JSON 转义。`accepted` 后才清空草稿。正常发送不轮询、不自动重发；重新打开生成中的历史才每两秒恢复一次，最多 90 次。
- 使用 16kHz 单声道 WAV 录音，最长 60 秒，兼容服务端现有 ASR 输入。用户主动点击录音后请求小程序隐私授权和麦克风权限。页面隐藏时取消录音发送、终止流式连接、停止播放并清理定时器。
- 公开句子录音可直接播放。缺少录音时，后端允许使用个人 TTS 的账户会先看到费用确认，再请求生成；不以平台密钥兜底。
- 发音评分沿用现有 API，是语音识别与原文的匹配估算。练习保存失败时保留评分，可单独重试保存；不需要再次调用 ASR。客户端对复习提交设锁，收到成功后才计入完成并解锁下一题。
- 仅在可见学习页面发送学习时长心跳，间隔 30 秒。首页、我的和后台页面不产生学习心跳。
- 服务条款和隐私政策来自网站 `front/content` 的当前快照，隐私政策另附本版小程序的数据使用说明。网站文本变更时同步 `content/legal.js`。

微信公众平台的《用户隐私保护指引》需要按实际用途声明录音及处理方式；前端权限文案不替代平台配置。微信 API 依据：[腾讯维护的官方 API 类型定义](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts)。

## 检查

Node.js 18+：

```powershell
cd D:\Works\colang\website\miniprogram
npm ci
npm test
npm run check
```

`npm test` 使用原生 Node test runner 与 wx API 替身，覆盖鉴权、账户切换、服务端响应字段、流式分片与取消、录音清理、练习保存和密钥保留。

`npm run check` 验证所有 JS/JSON、页面入口、站内链接和事件绑定，并用 `miniprogram-compiler` 包封装的 wcc/wcsc 编译全部 WXML/WXSS，渲染游客、登录和核心交互状态。该工具只作为开发依赖，不进入小程序代码包。这些检查不替代真实微信运行环境。

本次没有启动真实微信客户端或调用付费 AI。真机联调时验证：邮箱注册 / 登录 → 配置个人 AI → 中文流式对话 → 录音对话 → 跟读保存 → 生词复习 → 切换账户；另查拒绝录音授权、前后台切换、断网恢复与安全区 / 键盘遮挡。
